# 轻量交付快照

本目录保存本次审计的样本索引、抽样规则、标签初始状态、版本表、核算与验证摘要，以及代理候选备忘。入口是 [审计报告](../attack-evidence-audit.md)。

完整本机材料在仓库 `data/attack_audit/20261020/`；原录像仍在工作区 recordings，未复制。复核工具保存标签到 data 下的工作副本，**不会自动更新本目录的交付快照**。再次交付时需明确导出，避免误把旧快照当新复核结果。

`candidates.json` 是代理稀疏帧观察，不是人工标签，也不是盲审首判。其余样本标签保持待审；不能将候选意见并入确认损伤或错误率。
